# Formação Analista de Dados

---

## 1. O que é a Formação Analista de Dados

A **Formação Analista de Dados** é uma formação da Asimov Academy criada para ensinar o aluno a sair do zero e percorrer o caminho completo para se tornar um **analista de dados com Python**.

A formação foi pensada para quem quer aprender a usar dados para tomar decisões melhores, construir análises profissionais, criar gráficos, manipular bases de dados, trabalhar com SQL, automatizar planilhas, criar dashboards interativos e comunicar insights com clareza.

O aluno começa pelos fundamentos: lógica de programação, instalação do ambiente Python, conceitos básicos e intermediários da linguagem, leitura e escrita de arquivos, e os primeiros passos em análise de dados com Python e Pandas.

Depois disso, a formação avança para os pilares de análise de dados: estatística, matemática aplicada, análise exploratória, manipulação de dados com Pandas, uso de SQL, bancos de dados PostgreSQL, integração entre Python e bancos relacionais, automação de Excel e criação de relatórios.

Por fim, o aluno chega na parte de visualização e dashboards: aprende a criar gráficos com Matplotlib, Seaborn e Plotly, desenvolver aplicações web com Streamlit e construir projetos práticos que simulam situações reais de mercado.

A formação tem **60h de conteúdo**, certificado de conclusão e uma estrutura prática, com cursos e projetos criados para fortalecer o portfólio do aluno.

Além disso, o aluno aprende fundamentos essenciais para atuar com dados, incluindo:

- lógica de programação;
- Python do zero;
- manipulação de arquivos;
- Pandas;
- SQL;
- PostgreSQL;
- estatística;
- matemática para análise de dados;
- análise exploratória;
- visualização de dados;
- gráficos profissionais;
- dashboards interativos;
- automação de Excel;
- criação de relatórios;
- comunicação de insights.

Em linguagem simples:

> A Formação Analista de Dados ensina uma pessoa a sair do zero e aprender a transformar dados brutos em análises, gráficos, relatórios e dashboards úteis — usando Python, Pandas, SQL, estatística e ferramentas modernas de visualização.

# 3. Como a formação está estruturada

A Formação Analista de Dados é organizada como uma trilha progressiva, indo do básico ao avançado.

A estrutura da página divide os cursos em três níveis:

- **Básico**
- **Intermediário**
- **Avançado**

A lógica é simples: primeiro o aluno aprende Python e fundamentos; depois aprende estatística, SQL, Pandas e análise; por fim aplica isso em visualizações, dashboards e projetos práticos.

# 4. Projetos incluídos na formação

A Formação Analista de Dados é construída em cima de projetos práticos. A ideia é que o aluno não aprenda apenas conceitos soltos sobre Python, estatística ou visualização, mas veja como esses conceitos aparecem em problemas reais de análise de dados.

Cada projeto ensina um padrão importante: criar relatórios, analisar indicadores econômicos, explorar séries históricas, montar dashboards, automatizar planilhas, gerar PDFs e criar sistemas conectados a banco de dados.

---

## Montando seu primeiro relatório profissional em dados

Neste projeto, o aluno aprende a criar um relatório profissional do zero como um analista de dados.

Em alto nível, o projeto mostra como transformar uma base de dados em uma entrega clara: análise, gráficos, explicações e conclusões organizadas em um formato que outras pessoas conseguem entender.

Tecnicamente, o aluno aprende a estruturar uma análise, limpar e organizar dados, criar visualizações, selecionar métricas relevantes, interpretar resultados e montar um relatório com raciocínio analítico e comunicação clara.

---

## Análise de dados de Obesidade e PIB

Neste projeto, o aluno analisa dados de obesidade mundial em adultos e PIB per capita.

Em alto nível, o projeto mostra como usar dados para investigar relações entre fenômenos sociais, econômicos e de saúde pública. O aluno aprende a sair da pergunta genérica e transformar dados em uma análise mais estruturada.

Tecnicamente, o aluno trabalha com bases reais, manipulação de dados em Python, cruzamento de variáveis, limpeza de informações, criação de gráficos, comparação entre países ou grupos e interpretação de padrões usando ferramentas de análise exploratória.

---

## Análise dos preços da gasolina no Brasil

Neste projeto, o aluno analisa os preços da gasolina no Brasil ao longo do tempo.

Em alto nível, o projeto mostra como trabalhar com séries temporais e dados econômicos que afetam a vida real. O aluno aprende a investigar variações de preço, tendências, comparações regionais e mudanças ao longo dos anos.

Tecnicamente, o aluno aprende a carregar e tratar dados históricos, manipular datas, agrupar informações, calcular métricas, criar gráficos de evolução temporal e comunicar conclusões a partir de dados públicos.

---

## SalesApp — Web App para controle e análise de vendas

Neste projeto, o aluno cria um web app para controle e análise de vendas.

Em alto nível, o projeto mostra como transformar uma análise em uma ferramenta interativa. Em vez de entregar apenas uma planilha ou relatório estático, o aluno cria uma aplicação onde é possível visualizar vendas, filtrar informações e acompanhar indicadores.

Tecnicamente, o aluno aprende a usar Streamlit para criar uma interface web, Plotly para gráficos interativos, Pandas para manipulação de dados e lógica de dashboard para apresentar métricas de vendas de forma visual e navegável.

---

## Gerando Relatórios PDF via Excel

Neste projeto, o aluno aprende a transformar dados de planilhas em relatórios PDF personalizados.

Em alto nível, o projeto resolve uma dor muito comum em empresas: parar de montar relatórios manualmente. A ideia é automatizar um processo repetitivo, pegando dados estruturados em Excel e gerando documentos prontos para envio ou apresentação.

Tecnicamente, o aluno aprende a manipular planilhas com Python, extrair dados de arquivos Excel, gerar relatórios personalizados, automatizar tarefas repetitivas e criar uma rotina que transforma dados tabulares em PDFs organizados.

---

## Criando Base de Dados com SQLAlchemy — Um CRUD completo

Neste projeto, o aluno aprende a criar uma base de dados SQL com SQLAlchemy e montar um CRUD completo.

Em alto nível, o projeto mostra como sair da análise isolada em arquivos e começar a trabalhar com sistemas que armazenam, consultam, atualizam e organizam dados de forma mais profissional.

Tecnicamente, o aluno aprende a usar SQLAlchemy, modelar tabelas, criar registros, consultar dados, atualizar informações, deletar registros e entender a lógica de um CRUD conectado a banco de dados.

---
