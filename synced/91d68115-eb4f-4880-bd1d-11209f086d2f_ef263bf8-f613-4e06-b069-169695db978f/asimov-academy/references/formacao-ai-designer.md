## 1. O que é a Formação AI Designer

A **Formação AI Designer** é uma formação da Asimov Academy criada para ensinar o aluno a criar **sites, interfaces, landing pages, dashboards e webapps com aparência profissional usando inteligência artificial**, sem precisar escrever código do zero.

A proposta da formação é mostrar como usar IA para transformar referências visuais, design systems, prompts e ferramentas modernas em interfaces reais, com HTML, CSS, JavaScript, animações, microinterações e acabamento visual de alto nível.

Em vez de usar IA apenas para gerar layouts genéricos, a formação ensina um fluxo mais profissional: o aluno aprende a extrair a lógica visual de referências, identificar tipografia, cores, espaçamentos, componentes, padrões de interface e transformar tudo isso em páginas web funcionais.

A formação começa pelo conceito de **Vibe Design**: uma forma de criar interfaces com IA a partir de referências visuais, intenção estética e direção criativa. O aluno aprende a usar a IA não apenas como uma ferramenta que “cospe código”, mas como uma parceira para interpretar estilos, recombinar elementos visuais e construir páginas com identidade.

Depois disso, o aluno aprende a usar ferramentas de IA para criar imagens profissionais para sites, landing pages e e-commerce, modernizar sites antigos, construir páginas estáticas de alto nível, criar portfólios visuais e desenvolver interfaces com animações 3D, scroll, interações e efeitos avançados.

Além disso, a formação ensina fundamentos práticos importantes para quem quer criar interfaces modernas com IA, incluindo:

- como usar referências visuais com IA;
- como extrair design systems;
- como gerar HTML, CSS e JavaScript com IA;
- como criar sites estáticos de alto nível;
- como modernizar páginas antigas;
- como criar imagens profissionais com IA;
- como usar animações, scroll effects e microinterações;
- como criar dashboards e webapps com visual profissional;
- como combinar IA com WordPress e Elementor;
- como criar interfaces com Canvas e WebGL;
- como usar Google Antigravity para criar sites, sistemas e automações.

Em linguagem simples:

> A Formação AI Designer ensina uma pessoa a sair dos layouts genéricos criados por IA e passar a construir interfaces visuais profissionais — usando IA para criar sites, landing pages, portfólios, dashboards e webapps com identidade visual, animações, código funcional e acabamento de alto nível.

Não precisa saber programar profundamente.
